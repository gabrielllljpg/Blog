Blog Modelo conceitual e lógico de um banco de dados  

Notação Chen:  

Identificação e criação das entidades: identificar os conceitos centrais do sistema (USUARIO, POST, COMENTARIO) e representá-los como as entidades principais no diagrama.  

Detalhamento com atributos e chaves: definir as propriedades de cada entidade (seus atributos) e estabelecer as chaves primárias (PK) e as chaves estrangeiras (FK).  

Conexão das entidades com relacionamentos: estabelecer as conexões lógicas entre as entidades, representando as regras de negócio do sistema (Por exemplo: um usuário escreve um post).  

Definição da cardinalidade: especificar as cardinalidades de cada relacionamento, utilizando a notação visual apropriada na ferramenta para finalizar o diagrama ER.  

Modelo Lógico:  

Mapear as entidades do diagrama ER criado no passo 1 para tabelas no modelo relacional.  

Inserir os atributos e chaves, incluindo as chaves estrangeiras (FKs) que não são descritas no diagrama ER feito com a notação Chen. 

Mapear os relacionamentos e suas cardinalidades, lembrando que entidades associativas no diagrama ER se tornam tabelas no diagrama do modelo relacional.
